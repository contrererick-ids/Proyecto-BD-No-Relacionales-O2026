Aplicación de consola en Python para gestionar la información de servicios y sitios web del sector turístico: reservas de paquetes de vuelos, viajes, tours y recomendaciones.

## Contexto académico

Proyecto semestral final de la materia **Bases de Datos No Relacionales** del **Instituto Tecnológico y de Estudios Superiores de Occidente (ITESO)**, periodo **Otoño 2026**.

**Objetivo:** demostrar los aprendizajes del curso mediante el uso de tres motores de bases de datos NoSQL.

| Motor | Tipo |
|-------|------|
| Apache Cassandra | Columnar |
| MongoDB | Documental |
| Dgraph | Grafos |

## Instalación y ejecución

### 1. Clonar el repositorio

```bash
# HTTPS
git clone https://github.com/contrererick-ids/Proyecto-BD-No-Relacionales-O2026.git

# SSH
git clone git@github.com:contrererick-ids/Proyecto-BD-No-Relacionales-O2026.git

# GitHub CLI
gh repo clone contrererick-ids/Proyecto-BD-No-Relacionales-O2026
```

### 2. Entrar a la carpeta del proyecto

```bash
cd Proyecto-BD-No-Relacionales-O2026
```

### 3. Crear y activar el ambiente virtual

```bash
python3 -m venv venv

# macOS / Linux
source venv/bin/activate

# Windows (PowerShell)
venv\Scripts\Activate.ps1
```

### 4. Instalar dependencias

```bash
pip install -r requirements.txt
```
